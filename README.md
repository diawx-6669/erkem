# Дворец королевы Еркем

Подарок от брата Ералы на 7-летие Еркем: сайт-игра и видео.
Сайт: https://diawx-6669.github.io/erkem/

## Что внутри

- **Вход**: подарок → лента → крышка → корона падает на фото → салют, Happy Birthday и королевский указ.
- **Тронный зал**: дворец в разрезе, на каждой двери фото и название комнаты.
- **17 игр**: «Дождь сюрпризов», «Задуй свечи», «Колесо фортуны», «Найди пару», «Пазл», «Лопни шарики»,
  «Наряди королеву», «Фотобудка», «Сколько мне тут лет?», «Ритм-сердечки», «Замри!», «Повтори движение»,
  «Крокодил», «Кто знает Еркем?», «Горячая картошка», «Челленджи», «Правда или задание».
- **Королевская казна**: выигранные купоны. Родители нажимают «Использовать» — купон гасится штампом «ИСПОЛНЕНО».
- **Звёзды**: за игры дают звёзды, за 7 звёзд открывается секретная комната с письмом и видео.
- **Альбом** «Как росла королева» и **финал** с семью коробочками-пожеланиями.

## Как поменять тексты без кода

| Файл | Что там |
|---|---|
| `data/prizes.json` | Призы и задания: `text`, `emoji`, `weight` (чаще/реже), `type` (`bonus`/`task`), `once: true` — только один раз. `bonusChance` — доля призов (0.65 = 65 %). |
| `data/quiz.json` | Квиз «Кто знает Еркем?»: впишите правильные ответы в `answer`, игроков — в `players`. |
| `data/games.json` | Слова для «Крокодила», челленджи, «Правда или задание», танцевальные движения, 7 пожеланий. |
| `data/photos.json` | Подписи к фото и возраст (для альбома и игры «Сколько мне тут лет?»). |

Прогресс и купоны сохраняются в браузере (localStorage) на том устройстве, где играли.

## Видео

`erkem-video.mp4` (1080×1920, для телефона) и `erkem-video-tv.mp4` (1920×1080, для телевизора), 76 секунд.
Исходники — в `video/`: сцены `scenes.html` + `scenes.js` (GSAP), музыка `music.py` (своя аранжировка Happy Birthday),
рендер `render.js` (Playwright покадрово → ffmpeg).

```sh
python3 -m http.server 8123 &          # из корня репозитория
python3 video/music.py video/build/music.wav
node video/render.js v                 # вертикальное
node video/render.js h                 # для телевизора
```
